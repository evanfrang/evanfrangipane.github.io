I have been playing around with simulating light and optics and created this python project 
which utilizes the Angular Spectrum Method (ASM).
The project is called [LightPy](https://github.com/evanfrang/lightpy).

Currently, I have three experiments operational which are single slit, double slit, circular aperture, and diffraction grating is somewhat working.
